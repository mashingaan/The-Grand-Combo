## Результаты gate

### Обычный движок

Прямой запуск `v2game.exe` с дескриптором дошел до загрузки и показал окно ошибки. Прямой запуск vanilla в этой установке также завис без игрового окна. Поэтому результат нельзя честно приписать TGC. Нужен ручной запуск через штатный launcher.

### Project Alice 1.3.0

Сценарий `real_economy.bin` был создан. Диагностический журнал содержит:

- 13 сообщений `Event given too many options`
- 197 строк с проблемами OOB и soldier
- 6 сообщений об invalid tag
- 0 совпадений `NaN`
- 0 совпадений `#inf`

Эта версия не проходит gate чистой совместимости.

### Project Alice main

Актуальный Alice собран локально в Release и SSE без ошибок компиляции. Исполняемые файлы заменили только ранее добавленные файлы Alice.

Первый перенос сборки был неполным. Launcher импортирует `luajit.dll`, а библиотека не была скопирована из `project-alice/libs`. Из-за этого Windows показывала системную ошибку до входа в код launcher. Библиотека добавлена, после чего launcher остается запущенным и системная ошибка не воспроизводится.

Свежий `Alice.exe` загружает сценарий 1.3.0 в headless-режиме без немедленного падения, но симуляция не начала потреблять CPU. CLI-автосборка свежего сценария по-прежнему завершается без результата и без нового журнала. Новая игра, сохранение, загрузка и прогон до 1850 года пока не подтверждены.

## Решение

После проверки интерфейса Project Alice он исключен из основной архитектуры как непригодный для пользовательского сценария. Основой остается TGC на оригинальном движке Victoria II. Компоненты Alice убраны из папки игры в восстановимый архив на E:.

Переименованный путь `TGC-RealEconomy` старым движком не загружался, хотя launcher передавал descriptor. Рабочая установка сохраняет ожидаемые TGC имена каталога и descriptor. Отдельная версия обозначается только полем `name` внутри `TGC.mod`.

До первого экономического изменения нужно вручную пройти TGC через штатный Victoria II launcher. После запуска проверяем старт в 1836 году, сохранение, загрузку и прогон до 1850 года.

## Vanilla Extended Timeline

VET оставлен без изменений. Одновременно с TGC его включать не нужно. TGC уже задает окончание кампании в 9999 году, а VET перекрывает историю стран и создает лишний слой конфликтов.

## Лицензирование

До получения явного разрешения авторов TGC не распространяем полную измененную сборку. Локальный прототип и собственный патч ведем отдельно.
